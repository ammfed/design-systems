# Changelog: Material Agent Chat

## 1.0.0 - 2026-10-05

- Initial public release: a Material 3 design system for a staff tool with an AI assistant beside data-heavy screens, in light and dark and in both text directions.
- Colour: the Material 3 role set filled from one warm accent and a neutral scale, a success role, and two agent roles for values the assistant filled and the person has not confirmed. Every pair is measured at WCAG 2.1 AA in both themes. Two values move from the source they were built from so that a pair passes: the draft outline is the deeper accent step in light (4.19:1 on its tint), and the third chart series is a deeper amber in light (3.18:1 on the page).
- Type: the Material 3 roles from display to label, heavy tight headings, roomy body, nothing below 12px, and right-to-left families that switch with `dir`.
- Shape, elevation, state layers, space, window size classes and the standard motion scheme as Material 3 tokens, with a reduced-motion path.
- Components: the Material 3 set a data-heavy screen needs, a data table, filter bar and empty state, and the agent surfaces (chat sidebar, full-page chat, message, input, suggestion chips, result card, approval card, draft field and agent progress).
- A mapping from Material 3 roles to a typical chat framework's theme variables and slots.
- Icons: one outline set at one weight, referenced by name with its licence; no icon files are shipped.
- A `preview.html` that links the three stylesheets beside it and fetches nothing.
